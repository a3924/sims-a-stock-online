# 我的模拟人生 · A股版（在线版）

纯静态 HTML5 Canvas 股票模拟游戏。**在线版**：不打包全市场行情数据，开局/换池时按需从腾讯行情接口实时拉取所选标的的历史日 K。

- 全市场 5400+ 只 A 股 + 400 ETF 元数据内置（轻壳约 1.5MB）
- 每局随机抽取 18 只标的（白/蓝/妖/周期/ST 分类配比），联网拉取 5 年日 K
- T+1 交易、20 万本金、365 个交易日、14 个副图指标、CYQ 筹码峰在线合成
- 版本：v20260903.online1（与离线版存档互不兼容）
